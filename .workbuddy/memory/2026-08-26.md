# 2026-08-26

## EngineType / StorageEngineType 合并到 DatasourceType（全量统一）

完成 dataforge-server 枚举统一重构：

- `DatasourceType`（devops.enums）现为唯一类型，新增 `exec`(boolean)、`store`(boolean)、`language`(List<CodeType>) 三属性，并保留 `isExec/isStore/getLanguage/supportsLanguage/execTypes/storeTypes` 等方法。
- 已删除 `EngineType.java`（execution 包）与 `StorageEngineType.java`（devops.enums）。
- `DatasourceConfig` 移除 `storageEngine` 字段，改用 `datasourceType` + `store` 标志区分存储/计算。
- `ExecutionStrategyFactory.getStrategy(DatasourceConfig)` 通过 `resolveStrategyType(DatasourceType)` 复用原"存储引擎→计算引擎"映射（HIVE→KYUUBI、DORIS/STARROCKS/MYSQL/CLICKHOUSE/POSTGRESQL→DORIS、HBASE→HBASE、ES→DORIS、HUDI/ICEBERG→KYUUBI），避免 MYSQL/POSTGRESQL 既作存储又作计算策略的冲突。
- 全部 main + test 源已迁移并 `mvn test-compile` 通过；`CalciteDdlParserTest`、`CodeExecutionServiceValidateTest` 单测通过。

### 重要坑（下次注意）
- 用 `replace_all StorageEngineType → DatasourceType` 时，`StorageEngineType` 是 `resolveStorageEngineType` 方法名**子串**，会把方法名误改成 `resolveDatasourceType`，导致无法 override 抽象方法。需事后 grep `resolveDatasourceType` 修正回 `resolveStorageEngineType`。
- 同理 `EngineType` 是 `getEngineType/setEngineType` 的子串，禁止对 `EngineType` 做全局替换，只能精确替换 `EngineType.XXX` 常量与 `public EngineType getEngineType()` 类型位置。
- 调用过 `config.setStorageEngine(...)` 的测试需改为 `config.setDatasourceType(...)`（字段已删除）。

## 前端可达性补全（闭环重构）

- 修正映射：`STARROCKS` 的 `exec` 应为 `true`（StarRocks 兼具计算+存储），原默认映射误写为 `false`。`DatasourceType.java:30`。
- 新增 `DatasourceTypeMetaVO`（devops.vo）：暴露 `code/description/exec/store/language`，供前端区分计算/存储与支持语言。
- `GET /devops/datasource/types` 改为返回 `List<DatasourceTypeMetaVO>`（原为 `List<DatasourceType>`，因 `@JsonValue` 在 `code` 上只序列化为字符串，导致 exec/store/language 对前端不可见）。**该端点响应形态由 `string[]` 变为 `object[]`，前端需相应调整解析。**
- 新增 `DatasourceTypeMetaVOTest` 验证映射与序列化形态，`mvn test` 通过。

## 暴露执行引擎元信息端点

- 新增 `ExecutionEngineController`（`/devops/execution`）：
  - `GET /devops/execution/engines` → `Result<List<DatasourceTypeMetaVO>>`，委托 `CodeExecutionService.getAvailableEngines()`，前端可动态渲染「可选引擎 + 每种支持的语言」。
  - `GET /devops/execution/engines/supported?engineCode=&codeType=` → `Result<Boolean>`，委托 `CodeExecutionService.isExecutionSupported()`。
- 新增 `ExecutionEngineControllerTest`（Mockito 单元测试用例，验证委托与映射），`mvn test` 通过。
